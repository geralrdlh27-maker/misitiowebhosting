¿QUÉ SIGNIFICA DNS?

Domain Name
System

DNS es la abreviatura de Domain Name System. Su función consiste en asociar nombres de dominio con direcciones IP para que los dispositivos puedan localizar los servidores correspondientes.

01

Solicitud

El usuario escribe un dominio en el navegador.

02

Búsqueda

Se consulta el sistema DNS para encontrar la dirección asociada.

03

Respuesta

El sistema devuelve la dirección IP correspondiente.

04

Conexión

El navegador utiliza esa dirección para comunicarse con el servidor.

✦

El DNS hace posible que una dirección fácil de recordar pueda convertirse en una ubicación que las máquinas puedan interpretar.
