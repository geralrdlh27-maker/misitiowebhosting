03 / DESARROLLO

Ciclo de vida
de un sitio web

◌

Un sitio web no aparece terminado desde el primer momento. Su creación implica una serie de etapas que permiten convertir una idea en una plataforma funcional.

01
PRIMERA ETAPA

Planificación

Se determina qué problema resolverá el sitio, quiénes lo utilizarán y qué contenidos o funciones serán necesarios.

02
SEGUNDA ETAPA

Diseño

Se establece la organización visual de las páginas, incluyendo colores, tipografías, navegación y distribución de los elementos.

03
TERCERA ETAPA

Desarrollo

El diseño se transforma en un sitio funcional mediante código y diferentes tecnologías web.

04
CUARTA ETAPA

Pruebas

Se revisa el funcionamiento de enlaces, formularios, navegación, compatibilidad y diferentes elementos del sitio.

05
QUINTA ETAPA

Publicación

Los archivos se colocan en un servidor para que el sitio pueda ser consultado mediante Internet.

06
SEXTA ETAPA

Mantenimiento

Se realizan actualizaciones, correcciones, mejoras de seguridad y modificaciones de contenido cuando son necesarias.
