REGLAS DE COMUNICACIÓN

Para que dos dispositivos puedan intercambiar información necesitan seguir reglas comunes. Los protocolos establecen cómo se transmiten, reciben y organizan los datos.

01 HTTP

Transferencia de información web

Permite que los navegadores soliciten recursos a los servidores y reciban elementos como documentos y páginas web.

02 HTTPS

Comunicación protegida

Añade mecanismos de seguridad a la comunicación web para proteger los datos intercambiados durante la conexión.

03 FTP

Transferencia de archivos

Está diseñado para facilitar el intercambio de archivos entre equipos conectados a una red.

04 TCP/IP

Base de Internet

Conjunto de protocolos que permite organizar, direccionar y transportar información entre dispositivos conectados.

05 DNS

Resolución de nombres

Permite localizar servidores mediante nombres de dominio asociados con sus direcciones IP.

06 SMTP

Correo electrónico

Se utiliza para el envío de mensajes de correo electrónico entre servidores y sistemas de correo.

HTTP → DNS → TCP/IP → SERVIDOR

Diferentes protocolos trabajan juntos para permitir que una solicitud llegue hasta el servidor correcto y que la información pueda regresar al usuario.
